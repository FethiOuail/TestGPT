# Portfolio Theme

A simple portfolio starter built with HTML, CSS, JavaScript, and Bootstrap.

## Upload to GitHub

1. Create a new GitHub repository (e.g., `portfolio-theme`).
2. In this project folder, initialize git if needed:

   ```bash
   git init
   ```

3. Add and commit your files:

   ```bash
   git add .
   git commit -m "Initial portfolio theme"
   ```

4. Add the GitHub remote and push:

   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git branch -M main
   git push -u origin main
   ```

## Enable GitHub Pages (optional)

To host the portfolio from GitHub Pages:

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/root` folder, then save.
5. After a minute, your site will be available at:

   ```
   https://<your-username>.github.io/<your-repo>/
   ```

## Customize

Update the following in `index.html`:
- Your name and bio
- Email/phone/location
- Social links

Update `script.js` to change the skills and projects data.
